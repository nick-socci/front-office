# Fantasy Baseball Analytics

A code-first analytics engineering project: ingesting live MLB and ESPN fantasy league data, transforming it with dbt, orchestrating with Dagster, and serving a Streamlit dashboard for live standings, projections, and waiver-wire recommendations.

**Status:** Planning complete, not yet started. See [HANDOVER.md](HANDOVER.md) for the full plan, architecture decisions, cost analysis, and open questions before picking this back up.
